Koffient (Kotlin efficient) - Kotlin (преимущественно нацелен на стек KMP) фреймворк, значительно упрощающий запуск и
локальный хостинг ML и DL моделей на мобильных устройствах в native. Фреймворк должен упростить ручную оптимизацию
моделей под мобильное железо, настройку inference runtime, взаимодействие с низкоуровневым native кодом, и подбор
конфигурации под конкретное устройство. Koffient должен представлять единый API, через который можно подключить модель,
оптимизировать ее под доступное железо и запустить локально с минимальным количеством дополнительной настройки.

Основной стек проекта - Kotlin KMP для публичного API и интеграции с приложениями, Rust для native слоя (с 26 сентября
2026 года официально поддерживается NVIDIA для разработки CUDA ядер и будет предпочтительнее C++ в данном проекте из-за
memory safe) и взаимодействия с системными backend, а также Python для tooling, конвертации, анализа и подготовки
моделей.

Главная задача фреймворка - решить отсутствие единого SDK для KMP (и в целом - мобильных) разработчиков в области
локального запуска моделей глубокого и машинного обучения.
